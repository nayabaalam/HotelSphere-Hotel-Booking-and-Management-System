DATABASE INTELLIGENCE

SQL Report Catalogue

Oracle SQL queries for accessing hotel business reports.

Oracle Database
01

Room Occupancy Report

View room availability and occupancy information.

SELECT * FROM hs_v_room_occupancy;
02

Daily Revenue Report

Review revenue generated on a daily basis.

SELECT * FROM hs_v_daily_revenue ORDER BY revenue_date DESC;
03

Monthly Booking Statistics

Analyze booking activity across different months.

SELECT * FROM hs_v_monthly_booking_stats;
04

Outstanding Payment Report

Identify bookings with pending payment balances.

SELECT * FROM hs_v_payment_summary WHERE due_amount > 0;
05

Audit Log Report

Review recorded database activities and audit events.

SELECT * FROM hs_audit_log ORDER BY action_at DESC;
